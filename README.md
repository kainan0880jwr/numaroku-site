# numaroku-site

沼ろくのサポート・利用規約・プライバシーポリシー・特定商取引法に基づく表記のページ（静的な HTML。外部のパッケージ・スクリプト・解析ツールは使わない）。

| 作業 | コマンド |
|---|---|
| 下書きを作る（`draft/`、黄色の【要記入】と「下書き」の帯つき・検索エンジンに載せない設定） | `python3 -I tools/build.py` |
| 公開用を作る（`docs/`。【要記入】【確認事項】が残っていたら作らずに止まる） | `python3 -I tools/build.py --release` |
| 手元で見る | `cd draft && python3 -I -m http.server 8765 --bind 127.0.0.1` |

- 利用規約・プライバシーポリシーの原稿は `../../oshikatsu/legal/` の下書きだけに置く。ここには写さない（二重管理しない）
- 運営者名・問い合わせ先・制定日は `site.json` に書く。原稿の【要記入】がこの値に置き換わる
- 公開するのは `docs/` だけ（GitHub Pages の公開元：main ブランチの /docs）。`draft/` は Git に入れない
- 原稿を直したら `--release` で作り直し、`docs/` の差分を確かめてからコミット・push する
